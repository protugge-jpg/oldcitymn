## ✨ How to Use the New Features

### Viewing Modals
1. Open `index.html` in a browser
2. Click any room or trip card
3. Modal pops up with detailed information
4. Close by clicking X, clicking outside, or pressing Escape

### Updating Content
1. To change room details: Edit `roomData` object in `script.js`
2. To change trip details: Edit `tripData` object in `script.js`
3. To change images: Update URLs in HTML or JavaScript data objects
4. To add new items: Follow the pattern in the data objects and add HTML cards

### Customizing Colors
1. Open `style.css`
2. Find the `:root` CSS variables section
3. Update the color values
4. Changes apply throughout the entire site
