💼 Bookings Data Structure

Each booking includes:

{
  id: "REF...",
  type: "room" | "trip",
  guestName: string,
  guestEmail: string,
  guestPhone: string,
  amount: number,
  status: "confirmed" | "completed" | "cancelled",
  createdDate: ISO timestamp
}

🔄 Booking Flow

  1. Select Service - Click "Book Now" on a room or trip
  2. Fill Details - Enter dates, participants, and guest info
  3. Review Price - See calculated total price
  4. Proceed - Click "Proceed to Payment"
  5. Enter Payment - Fill in card details
  6. Confirmation - Receive booking reference and confirmation
  7. Admin Access - View and manage in admin dashboard
